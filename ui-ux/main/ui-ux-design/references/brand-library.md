# Brand inspiration library

These 74 documents are third-party, alpha-stage analyses from Awesome DESIGN.md, not official brand specifications. They are kept as reference data, not active skills. Read only a selected analysis.

Choose a reference when the user names a brand or a concrete design direction. Preserve the user's own identity and verify fonts/assets and important contrast pairs. Do not assume proprietary fonts are licensed or that every token is accessible. A web Apple-style surface is not native Apple Liquid Glass.

Common starting points: [Linear](brand-library/linear.app/DESIGN.md) for dark product marketing; [Stripe](brand-library/stripe/DESIGN.md) for gradient-led financial marketing; [Notion](brand-library/notion/DESIGN.md) for workspace-inspired surfaces; [Apple](brand-library/apple/DESIGN.md) for product imagery; [IBM](brand-library/ibm/DESIGN.md) for an enterprise direction. These are options, not default templates.
