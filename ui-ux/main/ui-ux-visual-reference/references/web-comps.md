# Website comps

Establish the page story and intended action. Choose composition from the brief: centered manifesto, image canvas, asymmetric editorial, split product demonstration, or another supported arrangement. Keep the headline, image scale, CTA, and visible viewport proportion coherent. Do not enforce one hero orientation on every brief.

For section references, use a readable horizontal frame per section when fidelity matters. Avoid squeezing an entire long page into one tiny contact sheet. A whole-page overview can be useful for rhythm when requested, alongside detailed frames as necessary. Keep palette, typography, shape, and assets consistent while allowing each section's content to determine its layout.

The prompt should specify:

- Section role and key content, including only text that needs to be visible.
- Composition anchor, type hierarchy, spacing, component states visible in the frame.
- Shared identity and image/illustration treatment.
- Intended viewport/aspect ratio and readable first-view proportions.
- Elements to omit because they would obscure that section's purpose.

Ensure proof sections demonstrate believable product value without invented endorsements. Marketing imagery may be art-directed; product demonstrations should remain recognizable and structurally plausible. Avoid repeating the same grid or image/text split merely to complete the set.

Inspect headline reflow, button readability, gutter rhythm, image framing, and continuity with adjacent sections. A desktop comp implies a responsive direction but does not verify mobile behavior. If mobile fidelity is required, provide a relevant narrow composition rather than claiming the desktop image proves it.
