# Cohesive brand-kit boards

A strong identity board explains one idea across several applications. Choose a readable grid and aspect ratio from the requested deliverable; a 2×3 or 3×3 overview is useful when the content warrants it. Leave consistent gutters and vary emphasis so every panel does not compete.

Possible panels include a logo/wordmark cover, construction or negative-space logic, palette, typography specimen, digital application, physical application, image direction, and a detail/pattern. Include only panels that demonstrate the identity. A board is not obliged to contain nine miniature mockups.

Base the mark on the brand's purpose. Combine no more ideas than the mark can communicate clearly; keep repeated marks and wordmarks consistent across panels. References can inform rhythm, texture, hierarchy, and imagery without supplying the exact logo or slogan.

Use sparse, readable text: the brand name, a short specific tagline, and a few useful labels. Avoid invented tiny body copy. Match photography, illustrations, materials, and texture to the brand metaphor and palette. Treat browser/device mockups as identity applications, not evidence of implemented software.

A generation prompt should state category/audience, promise/personality, core metaphor, logo concept, palette, type roles, grid/aspect ratio, desired panels, asset references, and text. Carry existing logos as actual references when supported instead of asking the generator to reconstruct them from memory.

Inspect the rendered board for warped logos, inconsistent variants, illegible words, arbitrary palette drift, distorted devices, and unrelated imagery. Revise specific defects. Deliver the board as a concept overview; exact token values and editable masters require separate source artifacts when requested.
