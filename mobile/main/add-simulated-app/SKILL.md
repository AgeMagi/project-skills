# Add a simulated app format

Read the destination's preview, model, persistence, export and disclosure contracts. Define supported platforms/states, preserved formats and integration scope. Extending an existing simulated app usually updates its contract rather than creating another app.

Research public/official evidence; record URLs, dates, platform/version and uncertainty. Build original rendering/assets. Use installed `research-ui-ux` for substantial research or `match-ui-reference` for supplied-reference comparisons when useful; neither is required.

Document the layout contract in the established location: model sharing, canvas/density/safe areas, regions, typography/tokens, metadata lanes, overflow/long content, disclosure and export clearance. Keep local geometry/tokens separate unless shared behavior changes.

Integrate existing dispatch, draft codec/controller, editor, preview, deterministic fixtures and exports; update existing routing docs. Map shared data intentionally; preserve stored drafts and unrelated renderers.

Verify dispatch/persistence, important geometry and shared consumers. Use goldens and runtime reference captures where appropriate. Update contract/source/test ownership together; report supported states, evidence and fidelity gaps.
